# seo

Regras e artefatos do motor SEO. Defaults globais ficam em `config/seo.json`; o que é operacional e gerado vive aqui.

Subpastas previstas:

- `schema/` — tipos JSON-LD (Article, VideoObject, CollectionPage)
- `canonicals/` — mapas de URL canônica por domínio e idioma
- `redirects/` — redirecionamentos entre hubs, idiomas e produtos
