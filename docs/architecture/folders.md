# Mapa de pastas

Camadas do motor e o que cada uma guarda. Sem páginas e sem componentes visuais neste estágio.

| Pasta | Guarda | Não guarda |
|---|---|---|
| `templates/` | Contratos de layout (revista, artigo, hub, vídeo) | Páginas publicadas |
| `components/` | Blocos reutilizáveis (ainda vazios) | UI implementada |
| `products/` | Verticais / marcas futuras | Páginas de produto |
| `languages/` | Cópia de interface e hreflang | Corpo editorial |
| `hubs/` | Clusters temáticos | Artigos completos |
| `videos/` | Metadados de vídeo editorial | Binários pesados |
| `assets/` | Mídia de origem | Arquivos já publicados no host |
| `content/` | Fonte editorial (artigos, edições, traduções) | Layout |
| `data/` | Taxonomias, autores, keywords | Texto longo |
| `public/` | Artefatos estáticos do host | Conteúdo de origem |
| `seo/` | Schema, canonicals, redirects | Defaults globais |
| `config/` | Domínios, idiomas, defaults SEO | Conteúdo |
| `docs/` | Documentação interna | Conteúdo publicado |
