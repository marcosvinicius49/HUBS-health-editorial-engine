# config

Configuração global do motor: domínios, idiomas e SEO.

Arquivos iniciais:

- `domains.json` — hosts e mapeamento de produto/idioma
- `languages.json` — idiomas suportados e fallback
- `seo.json` — defaults de SEO (title, robots, hreflang)

Regras operacionais (schema, canonicals, redirects) ficam em `seo/`. Artefatos servidos (sitemaps) ficam em `public/`.
