# content

Fonte editorial do motor: textos, edições e traduções de corpo.

Não colocar páginas aqui. Cada peça de conteúdo referencia produto, hub, idioma e template.

O Astro lê Markdown (`.md`, `.mdx`) e JSON (`.json`) nestas subpastas via collections em `src/content.config.ts`. Arquivos ainda não são obrigatórios.

Subpastas previstas:

- `articles/` — artigos e peças long-form
- `magazines/` — edições e sumários de revista
- `translations/` — versões de corpo por idioma
